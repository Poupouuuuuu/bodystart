# SEO on-page — gabarits BodyStart

## Titles

Formats par type de page (suffixe global ` | BodyStart Nutrition` ajouté automatiquement par le template Next.js — ne pas le répéter) :

| Type | Format | Exemple |
|---|---|---|
| Fiche produit | `[Produit] — [catégorie/bénéfice]` | `Créatine Creapure — 100 % monohydrate micronisée` |
| Catégorie | `[Catégorie] : [promesse courte]` | `Protéines : whey, isolate et vegan testées` |
| Article | `[Question/sujet] : [angle]` | `Créatine avant ou après la séance : ce que dit la science` |
| Locale | `[Service] à [Ville] ([dépt])` | `Boutique de compléments alimentaires à Coignières (78)` |

Règles : mot-clé principal au début, ≤ 60 caractères avant suffixe, pas de keyword stuffing, un title unique par page (vérifier qu'aucune autre page ne cible la même requête).

## Meta descriptions

≤ 155 caractères. Structure : [réponse à l'intention] + [preuve/différenciateur] + [incitation]. Toujours inclure un élément concret (prix, dosage, délai, « en stock à Coignières »). C'est un texte d'annonce, pas un résumé : son seul but est le clic.

## Structure Hn

- **Un seul H1** par page, contenant le mot-clé principal (peut différer du title).
- H2 = sous-intentions de recherche (souvent les questions « People Also Ask » de Google — les chercher avant d'écrire).
- H3 = détails sous chaque H2. Jamais de saut de niveau (H2 → H4).
- Chaque section H2 doit pouvoir se lire seule (les IA extraient des sections, pas des pages).

## Fiche produit parfaite (checklist)

1. H1 = nom produit exact (avec la marque si recherchée : « Vapor X5 MuscleTech »).
2. Premier paragraphe : ce que c'est, pour qui, le bénéfice n°1 — en 2 phrases.
3. Bloc données : composition officielle, table VN, allergènes, format (= metafields). C'est LE différenciateur vs les fiches paresseuses des concurrents.
4. « Comment l'utiliser » : dose, timing, durée — en langage simple.
5. « Pourquoi chez BodyStart » : conseil en boutique, stock réel, Click & Collect Coignières, livraison France.
6. Description 150-300 mots uniques. Réécrire, jamais copier le fabricant (duplicate = invisible).
7. Image : alt = « [Produit] [marque] [format] — BodyStart Nutrition ».
8. Maillage : lier 2-3 produits complémentaires + la catégorie parente.

## Maillage interne

- Profondeur max 3 clics depuis la home pour toute page.
- Ancres descriptives (« notre whey isolate Volactive », jamais « cliquez ici »).
- Articles → produits (conversion) ; produits → articles (réassurance) ; tout → catégories (autorité).
- Après chaque publication : ajouter au moins 1 lien ENTRANT depuis une page existante à fort trafic.

## Longueurs indicatives

- Fiche produit : 150-300 mots de description (+ les données structurées qui comptent autant).
- Page catégorie : 100-200 mots d'intro au-dessus + grille produits.
- Article info : 800-1 500 mots si la requête le mérite — sinon plus court. La longueur n'est pas un objectif : couvrir l'intention, point.
